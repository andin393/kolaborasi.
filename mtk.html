MATEMATIKA

ANDIN FITRIANA PUTRI

dibuat oleh: Andin

Jawaban

Cara penyelesaian

Permisalan: x = harga satuan click clock y = harga satuan lampu hias CD Benruk SPLDV: 2x + y = 140.000
x + 3y = 195.000
Eliminasi Variabel x
2x + y = 140.000 *1
x + 3y = 195.000 *2

_________________ _
2x + y = 140.000
2x + 6y = 390.000

______________ _
-5y = -250.000
y = -250.000
______________
-5
y = 50.000
Subsitusi y:
2x + y = 140.000
2x + 50.000 = 140.000
2x = 140.000 - 50.000
2x = 90.000
x = 90.000
________
2
x = 45.000
kesimpulan:
jadi harga 1 click clock yaitu Rp45.000 dan harga 1 lapu hias dari CD yaitu Rp50.000

___________________

y = -270.000
__________
-5
y = 54.000
Subsitusi y:
2x + y = 210.000
2x + 54.000 = 210.000
2x = 210.000 - 54.000
2x = 154.000
x = 154.000
__________
2
x = 78.000
kesimpulan:
jadi harga 1 hiasan dinding yaitu Rp78.000 dan harga 1 gajah keyboard yaitu Rp54.000

MATEMATIKA

KEISYA ANANDHITA EKA SUCI

dibuat oleh : keisya

Jawaban

Cara penyelesaian

Permisalan: x = harga satuan robot
y = harga satuan tas
Bentuk SPLDV:
x + 3y = 270.000
2x + 3y = 315.000
Eliminasi:
x + 3y = 270.000
2x + 3y = 315.000
________________ _
-x = -45.000
x = 45.000
Subsitusi:
x + 3y = 270.000
45.000 + 3y = 270.000
3y = 270.000 - 45.000
3y = 223.000
y = 223.000
________________
3
y = 75.000
kesimpulan:
jadi harga 1 robot adalah Rp.45.000, sedangkan harga 1 tas adalah Rp.75.000.
